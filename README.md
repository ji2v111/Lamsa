# لمسة (Lamsa) — دليل المشروع

نظام إدارة سمعة للمحلات المحلية (مقاهي، صالونات، عيادات): بطاقة NFC/QR واحدة تعطي كل زبون نفس الخيارين دائمًا — تقييم على قوقل، أو رسالة مباشرة لصاحب المحل — بدون أي فلترة حسب الرضا.

---

## ١. الفكرة التقنية بإيجاز

- **رابط واحد ثابت لكل محل**: `/r/{slug}` — نفس الرابط يشتغل QR اليوم و NFC لاحقًا بدون أي تعديل كود.
- **لا فلترة تقييمات (Review Gating)**: كل زبون يشوف نفس الزرين بنفس الوزن دائمًا. التقييم الرقمي (لو أعطاه) يُستخدم فقط كسياق أولوية داخلي، لا يتحكم بأي عرض — هذا يحافظ على توافق كامل مع سياسة قوقل.
- **دورة اشتراك أوتوماتيكية**: تاريخ بداية/نهاية + مهلة سماح، تتحول تلقائيًا نشط ← فترة سماح ← موقوف بدون أي تدخل يومي، مع مفتاح إيقاف/تفعيل فوري منفصل كطوارئ.
- **ثلاث واجهات منفصلة**: لوحتك (المدير)، لوحة صاحب المحل (دخول برمز بريد، بدون كلمة مرور)، وشاشة الزبون العامة.

---

## ٢. التشغيل على جهازك (٥ دقائق)

```bash
cd lamsa_app
pip install -r requirements.txt
cp .env.example .env
uvicorn app.main:app --reload
```

افتح `http://127.0.0.1:8000/admin` — كلمة المرور الافتراضية `change-me` (غيّرها بملف `.env`).

بدون أي إعداد إضافي، التطبيق يشتغل محليًا بقاعدة بيانات `SQLite` تلقائية (ملف `local_dev.db`). هذا كافٍ للتجربة، لكن **لو حدّثت هيكلة الجداول من نسخة سابقة، احذف `local_dev.db` قبل التشغيل من جديد.**

## ٣. إعداد الخدمات الخارجية (مطلوبة فقط قبل النشر الفعلي)

### أ) قاعدة بيانات دائمة — Supabase (مجاني)

1. أنشئ حساب على [supabase.com](https://supabase.com) ومشروع جديد
2. من القائمة الجانبية: **Project Settings → Database → Connection string → تبويب URI**
3. انسخ الرابط (يبدأ بـ `postgresql://...`) — هذا هو `DATABASE_URL`

Supabase مجاني بدون حد زمني ينتهي بعده تلقائيًا، بعكس بعض المنصات.

### ب) إرسال البريد (رموز الدخول + رسالة الترحيب) — Gmail مجانًا

1. فعّل التحقق بخطوتين على حساب Gmail اللي بترسل منه
2. **Google Account → Security → App passwords** → أنشئ كلمة مرور تطبيق جديدة (اختر Mail)
3. هذي القيم تروح لـ `SMTP_USERNAME` (بريدك) و`SMTP_PASSWORD` (كلمة مرور التطبيق، ١٦ حرف بدون مسافات)

**بدون هذا الإعداد**: النظام يشتغل عادي، لكن رموز الدخول ورسائل الترحيب تُطبع بسجل التشغيل (terminal) بدل ما توصل بريد فعلي — مفيد للتجربة قبل الربط الفعلي.

### ج) تنبيه فوري للمدير — Telegram (اختياري، مجاني)

1. افتح Telegram وابحث عن `@BotFather` → أرسل `/newbot` واتبع الخطوات → يعطيك توكن (`TELEGRAM_BOT_TOKEN`)
2. خلي صاحب/مدير كل محل يرسل أي رسالة للبوت من حسابه
3. افتح بالمتصفح: `https://api.telegram.org/bot<التوكن>/getUpdates` → تلقى `"chat":{"id": 123456789}` — هذا رقمه
4. من لوحتك: افتح المحل → قسم "تنبيهات المدير" → الصق الرقم → فعّل الخانة → احفظ

## ٤. النشر الفعلي — خطوة بخطوة (Render، مجاني)

> جهّز الخطوة ٣-أ (Supabase) قبل ما تبدأ هنا — تحتاج رابط قاعدة البيانات بالخطوة ٥.

1. **ارفع المجلد على GitHub**: أنشئ repository جديد (خاص أو عام)، ارفع محتويات `lamsa_app` بالكامل له
2. **أنشئ حساب على [render.com](https://render.com)** (تقدر تسجل بحساب GitHub مباشرة)
3. من لوحة Render: **New → Web Service** → اربط الـ repository اللي رفعته
4. عبّي إعدادات البناء:
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
5. من تبويب **Environment**، أضف المتغيرات التالية (كلها من الخطوات أعلاه):

   | المتغير | القيمة |
   |---|---|
   | `DATABASE_URL` | رابط Supabase (الخطوة ٣-أ) |
   | `BASE_URL` | رابط موقعك على Render بعد إنشائه (مثل `https://lamsa-xxxx.onrender.com`, بدون `/` بالنهاية) |
   | `ADMIN_PASSWORD` | كلمة مرور قوية من اختيارك |
   | `SESSION_SECRET` | أي نص عشوائي طويل |
   | `SMTP_USERNAME` / `SMTP_PASSWORD` | من الخطوة ٣-ب (اختياري لكن موصى به) |
   | `TELEGRAM_BOT_TOKEN` | من الخطوة ٣-ج (اختياري) |
6. اضغط **Create Web Service** — النشر يبدأ تلقائيًا، ويعطيك رابط جاهز خلال دقائق
7. **مهم**: بعد ما يطلع لك الرابط الفعلي، ارجع لمتغير `BASE_URL` وحدّثه بنفس الرابط بالضبط، ثم أعد التشغيل (Manual Deploy) — بدون هذا، روابط QR والبريد المُرسل بتشير لعنوان غلط

**تنبيه أداء**: الخطة المجانية بـ Render "تنام" بعد ١٥ دقيقة بدون زيارات، وأول طلب بعدها يتأخر ٣٠-٦٠ ثانية. الحل: أنشئ حساب مجاني على [cron-job.org](https://cron-job.org) واعمل ping لرابط موقعك كل ١٠ دقائق.

## ٥. أول استخدام بعد النشر

1. افتح `https://رابطك/admin` وسجّل دخول بكلمة المرور اللي حددتها
2. أضف أول محل: الاسم + بريد صاحب المحل + رابط تقييم قوقل (من Google Business Profile → Get more reviews)
3. صاحب المحل يستلم بريد ترحيب تلقائي فيه رابط الدخول
4. من صفحة المحل: حمّل صورة QR، جرّبها بجوالك بنفسك قبل ما تطبعها

---

## ٦. نظام التصميم

الألوان محسوبة فعليًا (مو تخمين بصري) لتحقق WCAG 2.1 AA — كل نص وحدّ فحصته رياضيًا ضد الخلفية. الوضع الفاتح والغامق متوفران بكل صفحة (زر أعلى الصفحة)، ويُحفظ اختيار الزائر بالمتصفح. الشعار والأيقونات (`app/static/`) تتلوّن تلقائيًا بالكود حسب الوضع، بدون أي نسخة منفصلة لكل واحد.

---

## ٧. هيكلة المشروع

```
app/
  main.py              — كل المسارات: بوابة الزبون + لوحة التحكم + بوابة صاحب المحل
  models.py            — Tenant / Membership / ScanEvent / Feedback
  database.py          — الاتصال بقاعدة البيانات (SQLite محليًا، Postgres فعليًا)
  config.py            — قراءة متغيرات البيئة
  emailer.py           — رموز الدخول ورسالة الترحيب (SMTP)
  notifiers/           — قنوات التنبيه (Telegram حاليًا، قابلة للتوسع)
  static/
    icons/              — الأيقونات، تتلوّن تلقائيًا حسب الوضع
    illustrations/      — الشعار، الرسمة الرئيسية، النقش، حالات فارغة/نجاح
  templates/           — كل الصفحات (Jinja2)
```

---

## ٨. إضافة قناة تنبيه جديدة (مثل واتساب لاحقًا)

بمجرد ما يوصل اعتماد Meta لواتساب:

1. أنشئ `app/notifiers/whatsapp.py` بنفس شكل `telegram.py` (نفس الدالتين `is_configured` و`notify`)
2. أضف سطر واحد بـ `app/notifiers/registry.py`:
   ```python
   AVAILABLE_NOTIFIERS = {
       "telegram_alerts": TelegramNotifier(),
       "whatsapp_alerts": WhatsAppNotifier(),
   }
   ```
3. فعّل خاصية `whatsapp_alerts` للمحل من نفس منطق `features` بقاعدة البيانات

لا حاجة لتعديل `main.py` ولا أي قالب HTML.
